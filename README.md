# 111, Inc. Investor Relations Concept

An independent design concept for the investor relations page of 111, Inc. (Nasdaq: YI). It is not the company's official site and is not affiliated with, endorsed by or approved by the company.

Figures are taken from the company's filings with the SEC (Form 20-F, the Forms 6-K and the buyer group's Schedule 13D), each linked beside the item on the page. The company is a foreign private issuer and reports in renminbi. No share price is shown. Statements that come from the company's own websites or releases are labelled as such and are not verified.

The page is a single self-contained HTML file with local images. Open `index.html` or visit the site.
